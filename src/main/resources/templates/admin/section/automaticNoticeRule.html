입력항목 안내

Region: KO는 한국어 문서, EG는 KO가 아닌 문서

Type: EXACT는 전체 일치, CONTAINS는 포함, REGEX는 전체 정규식 패턴 일치 시 매칭

Key: 협조문 C열에서 매칭할 챕터명 또는 항목명

Detail: 매칭됐을 때 협조문 D열에 자동 입력할 세부 검토사항

Teams: 매칭됐을 때 협조문 E열에 자동 입력할 담당팀

Priority: 숫자가 작을수록 먼저 검사하며 처음 매칭된 규칙만 적용

Alias: 현재 매칭에는 사용하지 않는 참고 메모

사용: Y는 자동완성에 사용, N은 DB에만 저장하고 자동완성에서 제외
