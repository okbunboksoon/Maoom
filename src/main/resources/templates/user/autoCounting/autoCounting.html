인쇄 배열표

AutoCounting DEV의 초판, 개정, 페이지 계산 흐름을 선택합니다.

1
작업 선택 초판 PDF를 분석하고 배열표 엑셀을 생성합니다.
2
초판 발주 정보 원본 PdfLayoutSwingOnly 입력 항목과 같은 구성입니다.
3
초판 옵션과 PDF PDF 확인은 자동 계산, 실행은 템플릿 엑셀 생성 단계입니다.
옵션
4
챕터 페이지 FM을 켜면 원본처럼 수동 입력값을 사용하고 PDF 분석은 건너뜁니다.
2
개정 발주 정보 기존 배열표 엑셀과 개정 TXT를 비교해 표시합니다.
3
개정 파일 TXT 첫 줄은 헤더로 건너뛰고, 엑셀 Input 시트 A열과 매칭합니다.
2
PDF 페이지 계산 원본 jar에서 이 화면은 PDF 확인으로 챕터 페이지 수만 표시합니다.
3
계산 결과 마지막 페이지가 빈 페이지인 챕터는 실페이지에서 제외하는 기준입니다.
